
# Collections Dashboard (Deployable Package)

This is a ready-to-deploy Next.js starter for your Performance Dashboard.

## Quick start (local)

1. Unzip the package.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the dev server:
   ```bash
   npm run dev
   ```
4. Open http://localhost:3000

The file `.env.local` is pre-filled with the Airtable API key and Base ID you provided.

## Deploy to Vercel
1. Create a Vercel account (https://vercel.com).
2. Create a new project and upload this repository (or connect your GitHub repo).
3. Ensure the ENV vars in Vercel match `.env.local` (or paste them in Project Settings).
4. Deploy.
